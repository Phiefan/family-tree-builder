# Git Branch Naming Conventions

| Prefix | Purpose | Example |
| :--- | :--- | :--- |
| **`feature/`** | New functionality | `feature/add-person` |
| **`fix/`** | Bug fixes | `fix/family-tree-rendering` |
| **`test/`** | Test-related work | `test/relationship-scenarios` |
| **`chore/`** | Tooling & maintenance | `chore/update-dependencies` |
| **`docs/`** | Documentation | `docs/add-user-stories` |
